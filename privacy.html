Gmail Filter ManagerTerms of use

Privacy policy

Effective date: October 24, 2026.

Gmail Filter Manager is a personal utility operated by the Google account owner. It is not offered as a public mailbox service.

Data accessed and purpose

The tool accesses Gmail filter definitions and label names and identifiers to display, validate, back up, and apply rule changes requested by the owner. Filter conditions may include sender or recipient addresses, subject text, and search queries. The application does not request access to email message contents and does not send messages.

Google Drive access uses the drive.file permission to create and manage the tool's backup files and files explicitly opened with the tool. The application does not request unrestricted Drive access.

Storage and security

Filter backups are stored in the owner's Google Drive. Older backups may remain in the owner's Apps Script user properties. The local command client can save requested exports on the owner's computer. Its runtime refresh token is encrypted with Windows DPAPI. Separate deployment credentials are managed locally by Google's clasp tool.

The management panel and API execution are configured for the owner only. The public website contains application information, not mailbox data, filter exports, credentials, or backup files.

Use and sharing

Google API data is used to provide the requested filter-management and backup functions. This application does not sell data, use it for advertising, or train general-purpose AI models.

Google processes the data needed to run Gmail, Drive, and Apps Script. If the owner instructs an automation assistant to inspect or change rules, filter configuration may also be processed by that assistant under the owner's instructions and its provider's policies. The Apps Script application itself makes no calls to external AI services.

Use and transfer of Google API data follow the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner controls backup retention and may delete Drive backups, legacy Apps Script backups, and local exports. Revoking authorization does not automatically delete existing backups or remove Gmail rules already applied. Authorization can be revoked in Google Account connections. Google may retain service records according to its own policies.

This public website

These static pages have no forms, application cookies, analytics scripts, or access to Gmail. GitHub Pages hosts the site and may process connection information under the GitHub Privacy Statement.
