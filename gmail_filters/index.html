Gmail Filter Manager

A private tool for reviewing Gmail filters, making precise rule changes, and keeping verified backups in the account owner's Google Drive.

What it does

  • Lists Gmail filter definitions and available labels.
  • Previews rule conditions and actions before applying a change.
  • Creates, replaces, or deletes rules only when instructed by the owner.
  • Saves and verifies a complete filter backup before each rule change.

The tool runs in the owner's Google Apps Script project. Its management panel and API are restricted to the owner. This public website only explains the tool; it does not provide account access or an authorization endpoint.

Google account access

The application requests Gmail filter settings, Gmail labels, and access to Drive files it creates or that the owner explicitly opens with it. It does not request permission to read message bodies or send mail. Rules can affect how future messages are handled by Gmail.

Filter backups can contain email addresses and other personal information in rule conditions. Backups, account tokens, and actual filter definitions are not published on this website.
